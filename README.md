# Less Screen Time — Sales Page

A fast, framework-free sales page for **“The Phone Is Not The Problem”** and its six practical family bonuses.

## Files

- `index.html` — page structure and sales copy
- `styles.css` — colours, typography, responsive layout, and components
- `script.js` — five-hour personal reminder and mobile sticky purchase button

## Local preview

Open `index.html` in a browser or serve the folder using any static HTTP server. No build step, dependencies, or environment variables are required.

## Vercel deployment

1. In Vercel, select **Add New → Project** and import `muhammed-codes/lessscreentime`.
2. Set **Framework Preset** to **Other**.
3. Leave **Root Directory** as the repository root (`./`).
4. Override the **Build Command** and leave it blank. Serve the repository root as the output directory.
5. Deploy, test on desktop/mobile, then attach your custom domain under **Project → Settings → Domains**.

All checkout buttons go to [Selar](https://selar.com/3j768222s7). This site does **not** process payments or deliver files.

### Launch checks

- Verify the listed ₦4,950 amount against Selar checkout.
- Confirm the Selar purchase flow and download access for the eBook plus six bonuses.
- Open the page in a private window and confirm all seven external product images display.
- Verify the five-hour timer counts down. It is a personal reminder, **not** a Selar price expiry.
- Test the refund-email link and every purchase button.

## Notes

The seven product images are currently hosted by an external image host. If any become unavailable, replace their `src` URLs in `index.html` with stable hosted assets before running paid ads.
